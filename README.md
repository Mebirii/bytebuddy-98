# ByteBuddy ’98

Jeu rétro autonome (HTML, CSS, JavaScript) sans dépendance extérieure.

## GitHub Pages

1. Dans https://github.com/Mebirii/bytebuddy-98, importer `index.html` et `.nojekyll` à la racine de `main` (ou accorder à ChatGPT/Codex les droits de modification du dépôt pour qu’il le fasse).
2. Ouvrir Settings > Pages > Build and deployment.
3. Choisir Deploy from a branch > main > /(root) > Save.
4. Vérifier https://mebirii.github.io/bytebuddy-98/ une fois le déploiement terminé.

Les sauvegardes sont locales au navigateur et ne sont pas synchronisées entre appareils.
